# AxonHubClient 项目看板

## 使用规则

- 新任务先放入 `待办`。
- 开始处理时移入 `进行中`。
- 遇到外部依赖或信息不足时移入 `阻塞`。
- 完成后移入 `已完成`，只保留简短结果说明。
- 每次更新只移动条目，不重复写长说明。
- 待办按优先级分为 `P0` / `P1` / `P2`，同一优先级内可按依赖顺序推进。
